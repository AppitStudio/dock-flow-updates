VERSION: 1.82
DETAILS:

new: Control ExtraDock through Talk – Presets can now show and hide ExtraDock docks over the Talk SDK instead of the legacy bridge, with both ExtraDock 4 and ExtraDock 5. Open Settings → Talk Integrations, click Connect… on the ExtraDock card, press Start Pairing in ExtraDock, compare the verification code in both apps and approve in ExtraDock. Access is saved per ExtraDock generation and reconnects on later launches without a new pairing. Requires ExtraDock 4.3.18 or ExtraDock 5.0.9 or later.
new: Live dock updates – With Talk connected, DockFlow receives ExtraDock's dock list and changes as they happen, so presets always act on the current docks.
new: Apps that can use DockFlow – Settings → Talk Integrations lists the apps allowed to control your presets with an Allowed / Needs attention status per app, plus Permissions… and Remove…. In the consent panel, Allow is enabled only after you confirm the code matches, and permissions are described in plain language.
new: Diagnostics page – Settings → Diagnostics → Export Logs… saves the last five hours of DockFlow's own log entries to a text file you can send to support. Nothing is uploaded automatically.
new: CLI honors Skip Reapplying Current Preset – DockFlowCLI apply now follows the Skip Reapplying Current Preset setting from the app, and --skip-if-active requests the same behavior for a single invocation. A skipped apply exits successfully without rewriting Dock preferences, restarting the Dock or closing applications.
improved: Bridge and Talk side by side – Settings → Integrations keeps the original ExtraDock bridge pane. While Talk controls ExtraDock, the pane shows a "Controlled through Talk" card; turn the bridge toggle on to switch back. At launch DockFlow uses Talk when a grant exists and the bridge otherwise, and an ExtraDock build without Talk support keeps working through the bridge.
improved: Presets reach ExtraDock reliably – Right after a preset restarts the macOS Dock, ExtraDock 5 briefly reports its docks as unavailable. DockFlow now retries those docks after 0.4 s and again after 0.9 s so the switch lands; timeouts and disconnects are never replayed.
improved: Clearer ExtraDock status – The ExtraDock card tells apart an ExtraDock that is running but not yet connected, a build without Talk support, an active bridge and a connected ExtraDock with no docks. When some docks did not apply, it reports a count per status and logs each dock's status and message.
improved: No surprise launches – Talk never launches ExtraDock on its own; only an explicit Connect does. Forget Connection removes DockFlow's own copy of the access, while ExtraDock keeps its grant until you revoke DockFlow there.
