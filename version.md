VERSION: 1.81
DETAILS:

new: Startup Preset – Choose a preset to activate automatically whenever DockFlow starts, including at login (General → Startup). If the preset uses ExtraDock, DockFlow waits for ExtraDock to be ready before applying it.
new: ExtraBar Integration – ExtraBar's new DockFlow widget can list your presets, show the active one and switch presets. Pair ExtraBar from Settings → Integrations → ExtraBar; access is explicit and can be revoked at any time.
